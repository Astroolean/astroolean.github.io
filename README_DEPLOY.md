# FatAshBOT GitHub Pages site

This folder is ready for `https://astroolean.github.io/` with no build step.

## Files to upload

Upload everything in this folder to the root of the GitHub repository that powers `astroolean.github.io`.

Expected root files include:

- `index.html`
- `styles.css`
- `script.js`
- `privacy.html`
- `terms.html`
- `404.html`
- `site.webmanifest`
- `robots.txt`
- `sitemap.xml`
- `assets/`

## GitHub Pages

For a user Pages site, the repository is normally named `astroolean.github.io`.

Once GitHub Pages is enabled for the repository, the public URLs are:

- Website: `https://astroolean.github.io/`
- Privacy Policy: `https://astroolean.github.io/privacy.html`
- Terms of Service: `https://astroolean.github.io/terms.html`

For the X developer app, the Website URL can therefore be:

`https://astroolean.github.io/`

The OAuth callback URL is a separate setting and should remain the exact callback used by FatAshBOT.

## Before publishing

Review the Privacy Policy and Terms of Service and adjust any wording that should reflect your exact distribution model before giving the site to outside users.
