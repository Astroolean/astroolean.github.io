FatAshBOT is designed around explicit controls rather than hidden browser tricks or mystery background behavior.

06 / FAQ

Clear answers.

Is FatAshBOT affiliated with X?

No. FatAshBOT is an independent desktop application. X and the X logo are trademarks of X Corp.

Does FatAshBOT scrape the X website?

No. The product architecture is built around the official X API v2 and supported authentication flows.

Where is application data stored?

FatAshBOT is local-first. Application settings, drafts, event history, candidate records, and analytics are stored locally on the user's machine unless an action explicitly needs to contact X or another configured local service.

Does every X feature work for every account?

No. X controls developer access, endpoint availability, authentication requirements, scopes, rate limits, and account permissions. FatAshBOT reports API failures rather than pretending access exists.

Does FatAshBOT require cloud AI?

No. AI assistance is optional. The current design supports a local Ollama-compatible model so generated text can remain on the user's machine.
