Privacy Policy

Last updated: September 15, 2026

Overview

FatAshBOT is a local-first desktop application developed independently by Astroolean. This policy explains the application's intended handling of data when the software is used.

Local application data

FatAshBOT is designed to keep application settings, drafts, candidate history, application events, analytics, and related operational data on the user's own computer in local application storage. The software does not require a FatAshBOT cloud account to store that local workspace data.

X account authorization

When the user connects an X account, FatAshBOT may use X-provided authorization tokens to access API functionality the user explicitly authorizes. Those credentials are used to communicate with the official X API. Available actions depend on the scopes, permissions, developer access, and policies controlled by X.

Information sent to X

When the user performs an action that requires the X API, the information required for that request is sent to X. Examples can include post text, reply text, search queries, target account identifiers, or other data necessary for the selected API operation.

Local AI

If the optional local Ollama integration is enabled, prompts are sent to the Ollama-compatible service configured by the user. A local Ollama installation can keep that processing on the user's own machine. If the user points FatAshBOT at a remote compatible service, that service's own privacy practices apply.

Website data

This public website is a static GitHub Pages site. FatAshBOT does not add its own analytics, advertising trackers, or marketing cookies to this site. GitHub may process technical request information as part of operating GitHub Pages under GitHub's own policies.

Data sharing

FatAshBOT does not sell personal information. The application only sends data to external services when that communication is required for a user-configured feature or user-requested action.

Security

No software can guarantee absolute security. Users are responsible for protecting their computer, developer credentials, account access, and any exported or backed-up application data.

Third-party services

X, GitHub, Ollama-compatible services, and any other third-party systems used with FatAshBOT operate under their own terms and privacy policies. FatAshBOT is not affiliated with X Corp.

Changes

This policy may be updated as FatAshBOT changes. The date shown at the top identifies the current published version.

Contact

For project-related questions, contact the developer through Astroolean on GitHub.
